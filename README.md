# Sobre

O programa tem como objetivo converter expressões matemáticas infixas em expressões pós-fixadas (Notação Polonesa Reversa)

Foi desenvolvido como estudo de pilhas para a aula de Estrutura de Dados.

# Notação Infixa

É a forma padrão de escrever expressões aritméticas e lógicas, onde o operador é colocado entre os operandos.

Ex.: A + B

# Notação Pós-fixa

Também conhecida como Notação Polonesa Reversa (RPN) é outra forma de escrever operações aritméticas, onde o operador aparece APÓS os operandos.

Ex.: AB+
